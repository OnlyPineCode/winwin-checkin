# winwin-checkin

微博 8 账号每日「做数据」打卡面板。**单文件、零依赖、离线可用**。

## 使用

打开 `index.html` 即可，不需要服务器、不需要联网。数据存在浏览器 localStorage 里。

### iPhone 安装到主屏幕

1. Safari 打开页面
2. 分享 → 添加到主屏幕
3. 之后从图标启动，全屏无地址栏，数据独立保存（不受 Safari 7 天清理影响）

## 功能

- **打卡**：8 个账号 × 各类任务的勾选 / 计数录入，支持切换日期补录
- **看板**：完成率、任务合计、各任务 / 各账号完成情况、趋势图、月历
- **设置**：
  - 账号与任务的增删改、排序、备选登录标记
  - 任务合计显示项勾选
  - **数据备份**：导出文件 / 复制文本 / 从文件或粘贴恢复
  - **自动快照**：每天首次打开自动存一份，防 iOS 清理缓存
  - **GitHub 云端备份**：上传到私有仓库 / 从仓库恢复，换设备或系统更新后可找回

## 数据存储

| localStorage key | 内容 |
| --- | --- |
| `wb-config` | 账号、任务、合计显示配置 |
| `wb-records` | 打卡主数据 |
| `wb-records-bak` | 自动快照 |
| `wb-bak-meta` | 快照元信息 |
| `wb-lastbackup` | 上次导出时间 |
| `wb-github` | GitHub 备份配置（含 token） |

> ⚠️ 数据只存在本机浏览器。换设备、清缓存、系统大版本更新都可能丢。请定期用「设置 → 数据备份 → 导出备份文件」或 GitHub 云端备份。
