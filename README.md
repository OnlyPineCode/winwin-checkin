# winwin-checkin

微博 8 账号每日「做数据」打卡面板。**单文件、零依赖、离线可用**。

## 使用

打开 `index.html` 即可，不需要服务器、不需要联网。数据存在浏览器 localStorage 里。

### iPhone 安装到主屏幕

1. Safari 打开页面
2. 分享 → 添加到主屏幕
3. 之后从图标启动，全屏无地址栏，数据独立保存（不受 Safari 7 天清理影响）

## 功能

- **打卡**：8 个账号 × 各类任务的勾选 / 计数录入，支持切换日期补录
  - 账号多时右下角有**快速定位悬浮球**（云朵图标）：点一下在球旁边弹出很小的账号菜单，点账号即跳到对应区域并高亮
  - 悬浮球**可拖到屏幕任意位置**，松手就停在原地、不做边缘吸附；位置会被记住（换机型 / 转屏会自动夹回可见区）
  - 菜单会跟着球走：球贴近底部时菜单自动上翻，球在左侧时菜单自动翻到右边
  - 菜单只列账号名、不限制数量，账号名过长会自动换行
  - 可在设置里关掉这个悬浮球（账号少于 4 个时自动隐藏）
- **底部导航**：字号 14px、高度 41px，底部留白已按 iOS 26 的实际情况收窄
- **看板**：完成率、任务合计、各任务 / 各账号完成情况、趋势图、月历
- **每日总结**：汇总区右上角「分享」按钮，一键复制当天数据报告
  - 格式：`任务名+数量`，任务之间用 `+` 拼接（例：`大屏3+净化12+盖楼20`）
  - 只包含当天有数值的任务；哪些任务参与，由每个任务的「参与每日总结」开关控制
- **设置**（默认展开，点标题可收起；右上角一键「全部收起 / 全部展开」）：
  - 账号与任务的增删改、排序
  - 账号类型标记，五档可选：**主账号 / 副账号 / 常规号 / 养号 / 抡博号**
  - 任务合计显示项勾选、是否参与每日总结
  - 打卡页「快速定位账号」悬浮球开关
  - **数据备份**：导出文件 / 复制文本 / 从文件或粘贴恢复
  - **自动快照**：每天首次打开自动存一份，防 iOS 清理缓存
  - **GitHub 云端备份**：上传到私有仓库 / 从仓库恢复，换设备或系统更新后可找回

> 账号类型只是分类标记，**不影响切号顺序**（顺序由设置页里账号列表的 ↑ ↓ 决定）。
> 需要改变完成率统计的，是任务的所属分组（「养号」组不计入）。

## 账号编号说明

记录按账号的**内部编号**（`a1`~`a8`）保存，所以**改昵称不影响已有数据**。
编号与设置页的显示顺序一一对应；用 ↑ ↓ 调整顺序时，数据会跟着账号一起移动。

## 数据存储

| localStorage key | 内容 |
| --- | --- |
| `wb-config` | 账号、任务、合计显示配置 |
| `wb-records` | 打卡主数据 |
| `wb-records-bak` | 自动快照 |
| `wb-bak-meta` | 快照元信息 |
| `wb-lastbackup` | 上次导出时间 |
| `wb-github` | GitHub 备份配置（含 token） |
| `wb-fab-pos` | 快速定位悬浮球的位置 |

> ⚠️ 数据只存在本机浏览器。换设备、清缓存、系统大版本更新都可能丢。请定期用「设置 → 数据备份 → 导出备份文件」或 GitHub 云端备份。
